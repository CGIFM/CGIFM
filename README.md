<div align="center"><h3>🧭 工程原则</h3></div>

| | |
|---|:--|
| **能离线就不联网** — 本地优先，账号和云不是必需品 | `Local-first` |
| **明文件胜过黑盒** — 数据用通用格式存，任何工具都能检查 | `Inspectable` |
| **说清边界** — README 里同时写「能做什么」和「不能做什么」 | `Honest` |
| **能一行命令就不写十页文档** — 上手成本本身就是功能 | `Low-friction` |
